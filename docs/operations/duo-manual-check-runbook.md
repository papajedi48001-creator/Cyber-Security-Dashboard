# Duo Manual Check Runbook

Duo แผนที่โรงพยาบาลใช้ไม่มี API สำหรับดึง log อัตโนมัติ Portal จึงบันทึก **ผลการตรวจด้วยมือ** ว่าใครตรวจ เมื่อไร และพบอะไร นี่ไม่ใช่การเฝ้าระวังแบบ real-time

## รอบการตรวจ

- ตรวจอย่างน้อยวันทำการละ 1 ครั้ง (ทุก 8 ชั่วโมงทำการ)
- ถ้าเกินรอบ หน้า Duo แสดง "เลยกำหนดตรวจ" และหน้า Executive แสดง "การตรวจ Duo ด้วยมือเลยกำหนด"
- ยังไม่เคยตรวจ แสดง "ยังไม่เคยตรวจ" ห้ามตีความว่าปกติ

## ขั้นตอน

1. เข้า Duo Admin Panel ด้วยบัญชีผู้ดูแลของตนเอง (ไม่ใช้บัญชีร่วม)
2. เปิด **Authentication Log** ดูย้อนหลัง 24 ชั่วโมง นับ
   - การยืนยันตัวตนที่ถูกปฏิเสธ (Denied)
   - Fraud report (ผู้ใช้กดแจ้งว่าไม่ได้เป็นคนขอ)
3. เปิด **Users** ดูจำนวนผู้ใช้ที่อยู่ในสถานะ bypass
4. เปิด **Administrator Actions** ดูการเปลี่ยนแปลงโดยผู้ดูแลในช่วงเดียวกัน
5. ใน Portal หน้า Duo กรอกเวลาที่ตรวจ, ติ๊กว่าตรวจ Authentication Log และ Administrator Actions แล้ว, ใส่จำนวนทั้งสาม และหมายเหตุ (ห้ามใส่ชื่อผู้ป่วยหรือข้อมูลส่วนบุคคล ใช้คำอธิบายสั้น ๆ เช่น "bypass 1 ราย ของแผนก IT ชั่วคราว")
6. กด "บันทึกผลการตรวจ"

## เมื่อพบสิ่งผิดปกติ

| พบ | ทำ |
|---|---|
| Fraud report ตั้งแต่ 1 ครั้ง | เปิด incident P2 ติดต่อผู้ใช้ทันที และระงับบัญชีถ้าผู้ใช้ยืนยันว่าไม่ได้ทำ |
| Denied จำนวนมากผิดปกติจากผู้ใช้คนเดียว | เปิด incident P3 ตรวจว่าเป็นการเดารหัสหรือไม่ |
| ผู้ใช้ bypass ที่ไม่มีเหตุผลรองรับ | ยกเลิก bypass แล้วบันทึกในหมายเหตุ |
| Administrator Action ที่ไม่มีใครรับทราบ | เปิด incident P2 |

ทุกการบันทึกถูกเก็บใน Audit Log พร้อมชื่อผู้ตรวจ
